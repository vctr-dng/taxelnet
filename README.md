# Taxelnet

Digital twin of a capacitive tactile sensor.

## Contributing

### pre-commit

This project uses [pre-commit](https://pre-commit.com/) :

```bash
uv tool install pre-commit --with pre-commit-uv
pre-commit install
```

### AI Usage

This project leverages AI agents and LLM to accelerate its development.
In particular, it uses the [code-review-graph](https://github.com/codegraph/code-review-graph) which can be installed as follows:

```bash
uv tool install code-review-graph --with igraph
```
